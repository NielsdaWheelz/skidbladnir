# session naming

[automatic session names and public handles](automatic-session-names.md) owns
the naming contract, schemas, ownership rules, content and acceptance.

there is one actual tmux name. a supplied creation name or saved rename is manual;
an omitted name follows the current active pane's terminal title. the rename sheet
can restore automatic ownership. external rename relinquishes automation.

session lifetime identifies attachment and closure. names never target those
operations. clients preserve drafts, focus and healthy attachments while titles
change; uncertain writes require inventory reconciliation and are never replayed.
