# native control restoration contract

the source pin is [`deployment/native-control/pin.json`](../deployment/native-control/pin.json). the dev-server installer is the only installation owner. it installs a private uv bootstrap, checks out the exact `llm-calling` commit, verifies that checkout's `uv.lock` digest, and runs `uv sync --python 3.12.13 --frozen --extra claude-sdk --no-dev` with uv 0.11.28. the frozen environment resolves `claude-agent-sdk==0.2.130`. it renders the source-owned [`skidbladnir-provider-runtime-control`](../deployment/native-control/skidbladnir-provider-runtime-control) launcher with the frozen venv's shell-quoted absolute path as `@ENVIRONMENT_SHELL@`, installs the source-owned [`claude`](../deployment/native-control/claude) shim at that venv's `bin/claude`, and installs the launcher as the gateway generation's `providers/native-control`. the stable `~/.local/bin/skidbladnir-provider-runtime-control` symlink reaches it through `current`; that absolute public command is `nativeControlPath` in skid's host config. the [deployment handoff](dev-server-handoff.md#profiles-and-shell-defaults) owns the exact ten-file receipt and symlink contract. the environment lives under `~/.local/share/skidbladnir/`; no shared herdr helper, account tree, or command is an input.

installation must fail before activating a gateway generation if the source commit, lock digest, tool versions, sdk version, entry point, shim, or launcher differs. stage a new revision beside the old one, then switch the gateway's `current` pointer atomically so gateway, helper launcher, shell assets, and plugin move together. retain the frozen environments needed by prior generations for rollback. do not let a marker file alone assert an intact environment; check the executables and installed versions. the installer and verifier must succeed with herdr-mobile absent.

the helper's claude adapter runs `claude agents --json --all` for inspection and `claude stop <id>` for a matched background session. its source uses `asyncio.create_subprocess_exec("claude", ...)`. the launcher puts its installed shim first in `PATH`, and fails if the shim is missing. the gateway passes the selected profile's absolute native executable as `SKIDBLADNIR_CLAUDE_COMMAND`; the shim executes exactly that path, removing the dispatch variable before entering claude. a missing native executable fails inside the shim and cannot fall through to a shared `claude` later in `PATH`. the gateway must also pass the profile's private `CLAUDE_CONFIG_DIR` before starting the helper; the helper's subprocess inherits it, and the pinned sdk history reader consults it. inherited `HERDR_*` variables must be removed. profile selection determines both values; a generic user `PATH` or shared work wrapper cannot select the account or executable.

qualification on macbook, 2026-09-25: a disposable checkout at `ec97adeb9ddd0f91b141f89cc42cff7cc7efdb8f` synced with uv 0.11.28 and python 3.12.13 using the frozen claude extra. a disposable no-auth helper inspection resolved the selected claude, inherited the private config directory, and returned the documented stale result. a separate launcher/shim probe dispatched to its exact native target; removing that target or shim failed without invoking a synthetic shared claude later in `PATH`. the installed native claude 2.1.282 exposes `agents --json --all` and `stop <id>`; `agents --json --all` against an empty disposable private config returned an empty json array. the pinned sdk's session reader explicitly reads `CLAUDE_CONFIG_DIR`. these are source and no-auth compatibility checks. they do not prove live status, saved-message coverage, or stop behavior with an authenticated session. those boundaries need approved live acceptance on each host after installation.

the tradeoff is an initial download, one private python environment per retained revision, and two short installed scripts. this buys an exact source and dependency boundary without changing the shared provider installation. the adapter's literal `claude` lookup makes the shim necessary until upstream accepts an explicit executable path; native provider upgrades still need requalification.
