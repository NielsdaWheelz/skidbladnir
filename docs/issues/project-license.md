# project license is unspecified

problem: the public repository has no project license file or stated project
reuse terms.

impact: readers cannot find the terms under which the project's own code may be
used or redistributed.

evidence: the documentation audit on 2026-10-01 found licenses for bundled
terminal and font dependencies, but no repository-level license. github reports
no detected project license. dependency notices do not specify terms for the
project's own code.

resolved when: the owner chooses and publishes the project's terms, and the
readme links to them. this documentation pass makes no licensing decision.
