# module rules describe an absent product

problem: `docs/rules/modules` prescribes tenant machines, provisioning backings,
replay keys, warm pools, semantic retrieval and project web state. those owners
do not exist in this repository.

impact: mandatory guidance invites machinery that the tmux architecture excludes.

evidence: `modules/machine.md` specifies provisioning and warm pools;
`modules/index.md` lists the other foreign features. the source implements
local tmux sessions and independent gateways instead.

resolved when: remove inapplicable specifications, retain only rules with an
actual owner, and repair documentation links. use source-reference and link
checks; an integration test cannot establish documentation applicability.
